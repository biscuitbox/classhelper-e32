사전 설치 안내문 — 복사해서 보내기

메신저·공문에 그대로 붙여넣기
[교탁 도우미 연수 — 사전 설치 안내]

연수 첫 시간에 바로 보드에 올릴 수 있도록, 아래 세 가지(필요하면 네 가지)를 미리 설치해 와 주세요. (Windows 노트북 기준, 20~30분)

1. 아두이노 IDE 2.x
   arduino.cc/en/software 에서 Windows용을 받아 설치합니다. 드라이버 설치를 물으면 모두 '설치'.

2. 보드 패키지 — esp32 by Espressif Systems (3.x)
   아두이노 IDE 왼쪽 두 번째 아이콘(보드 매니저) → esp32 검색 → 설치. 10분쯤 걸립니다.
   (검색이 안 되면 File → Preferences → Additional boards manager URLs 에
    https://espressif.github.io/arduino-esp32/package_esp32_index.json 을 넣고 다시 검색)

3. 라이브러리 — LovyanGFX
   왼쪽 세 번째 아이콘(라이브러리 매니저) → LovyanGFX 검색 → 설치.

4. (보드를 꽂았는데 포트가 안 보일 때만) USB 드라이버 — CH340
   보드의 USB 칩이 CH340C 입니다. 연수 사이트에서 받기: https://biscuitbox.github.io/classhelper-e32/downloads/CH341SER.EXE
   (제조사 WCH 누리집 wch-ic.com 의 CH341SER.EXE 와 같은 파일) → 실행 → INSTALL.
   장치 관리자 → 포트(COM & LPT)에 'USB-SERIAL CH340 (COM○)'이 보이면 됩니다. 대부분의 노트북은 저절로 설치됩니다.

※ Windows 사용자 이름이 한글이면(C:\Users\홍길동) 업로드 때 'cannot find -l…' 오류가 납니다.
   설치 후 아래처럼 옮겨 두면 연수장에서 막히지 않습니다.
   ① 아두이노 IDE를 닫고, C:\arduino 폴더를 만든 뒤 %LOCALAPPDATA%\Arduino15 폴더를 복사해 C:\arduino\data 로 이름 바꾸기
   ② 메모장으로 %USERPROFILE%\.arduinoIDE\arduino-cli.yaml 을 열어 directories: 아래를 이렇게 고치고 저장
        data: C:\arduino\data
        downloads: C:\arduino\staging
        user: C:\arduino\sketchbook
   ③ IDE를 다시 열고 보드 매니저에 esp32 가 설치됨으로 보이면 끝

준비물: 블루투스가 되는 노트북, 노트북 충전기, 구글 계정(제미나이 사용). 3차시에는 수업에 쓰는 PPT 파일 하나.
연수는 2인 1조로 보드 하나를 함께 씁니다. 두 분 모두 노트북에 위 설치를 해 와 주세요(한 대가 안 될 때 바로 바꿀 수 있게).
보드와 케이블은 연수장에서 드립니다.
학교망에서 내려받기가 막힐 수 있으니 가능하면 집에서 설치해 주세요.

연수 전 실물 점검 — 보드로 꼭 확인

코드는 PC에서 컴파일(플래시 96%)과 화면 시뮬레이션까지 확인했지만, 아래는 실제 보드로만 확인할 수 있습니다. 저항식 터치 · DAC 소리 · 블루투스는 이 보드로 아직 실물 확인 전이라, 한 대로 먼저 끝까지 해 봐 주세요.

  • ① 시작 코드가 올라간다Board ESP32 Dev Module · Huge APP · PSRAM Disabled. 포트가 안 잡히면 CH340 드라이버.
  • ② 화면 색이 맞다첫 화면 바탕이 짙은 남색, 지뢰찾기 칸이 회색인지. 필름처럼 뒤집혀 보이면 config.h 의 LCD_INVERT 1, 빨강·파랑이 바뀌면 LCD_BGR 1 — 바꾸면 시작 코드 zip도 다시 만들어 올리기.
  • ③ 터치 보정 → 점검 화면에서 점이 손끝에 찍힌다네 귀퉁이 보정 뒤 설정 → 점검에서 확인. 모든 보드를 미리 보정해 두면 연수 때 바로 씁니다(보정값은 코드를 다시 올려도 남음).
  • ④ 효과음이 난다스피커를 꽂고 점검 → [효과음]. 작으면 sfx.h 의 DAC_BOOST 를 3으로, 안 나면 config.h 의 AMP_ON_LEVEL 을 HIGH 로.
  • ⑤ 노트북과 블루투스로 연결된다설정 → 블루투스 → 장치 추가 → ClassHelper-01. 프레젠터 점이 초록, PPT 넘기기·포인터·소리 조절. Windows 10·11 둘 다 확인하면 좋습니다.
  • ⑥ 다른 노트북으로 옮겨진다첫 노트북 블루투스를 끄고 둘째 노트북에서 장치 추가 → 초록. 다시 첫 노트북을 켜면 돌아오는지(2인 1조 3차시).
  • ⑦ 타이머 신호등 완성 코드가 돈다1분 → 노랑 → 빨강 + 알림음 + LED 깜빡. 큰 화면·BOOT로 시작·멈춤.
  • ⑧ 절전에서 깨어난다설정 → [절전] 뒤 화면을 꾹 누르거나 BOOT로 깨어나는지. 배터리로 1시간쯤 버티는지도.
  • ⑨ PPT·구글 슬라이드 단축키Ctrl+L·Ctrl+P·Ctrl+E·Ctrl+A·E·Alt+P·Ctrl+H, 구글의 Ctrl+Shift+F5·Ctrl+F5. 쓰는 오피스 버전에서 한 번씩.

2인 1조 운영

언제어떻게
자리 배치두 분이 나란히. 우리 조 노트북(설치가 잘 된 쪽) 한 대를 가운데에, 다른 노트북은 워크벤치를 띄워 옆에.
1차시 시작조 번호 스티커와 블루투스 이름을 함께 정합니다 (예: 3조 → Team3-…).
실습 중운전석(키보드) · 조수석(워크벤치 읽기 · 보드 눌러 확인). 슬라이드의 "자리를 바꿉니다"에서 사람만 바꿉니다.
3차시먼저 우리 조 노트북에 연결 → 내 PPT로 써 본 뒤 짝 노트북으로 옮겨 연결(블루투스 끄고 장치 추가).
연수 뒤보드 주인을 정하는 방법(추첨·학교별)을 미리 정해 안내합니다. 코드는 워크벤치에서 누구나 다시 받을 수 있습니다.
운영 팁
  • 한 분만 계속 키보드를 잡지 않게, 자리 바꾸는 시점을 소리 내어 알려 주세요.
  • 두 노트북 모두 설치가 안 된 조는 강사 시연용 노트북을 빌려 주거나 옆 조와 화면을 함께 봅니다.
  • 조수석이 할 일이 없어 보이면 "빨간 오류 맨 위 세 줄을 찾아 AI에게 보낼 문장을 써 주세요"처럼 역할을 줍니다.

프롬프트 검증

워크벤치의 프롬프트는 AI 답이 매번 조금씩 달라서, 연수 전에 제미나이로 한 번씩 돌려 컴파일까지 확인해 두면 안심입니다.

프롬프트확인할 것
1차시 ①②③"찾을 줄"이 실제로 app_mine.h 에 있는지 (Ctrl+F)
2차시 ①컴파일 · 첫 화면 칸이 켜짐(ready=true) · 숫자가 1초마다 · delay() 없이 millis()
2차시 ②③Preferences 저장 · 노랑 1/4 · 끝나면 알림음 한 번과 LED 깜빡 · stop() 에서 LED 끄기
3차시 ①컴파일 · 연결 전 안내 화면 · BOOT = 다음
3차시 ②③펜 드래그 · 타이머가 다른 탭에서도 흐름
자주 나오는 AI 실수
  • helper.h 에 없는 함수 이름을 지어냄 → "helper.h 에 있는 함수만 써 줘"
  • delay() 를 길게 써서 터치가 굳음 → "delay 대신 millis 로"
  • app 의 마지막 값을 false 로 둠 → 첫 화면 칸이 회색 그대로
